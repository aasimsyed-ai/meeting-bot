# Risk register

Likelihood and impact: High, Medium, Low. Review before each release.

| ID   | Risk                                                                                                     | Likelihood | Impact | Mitigation in place                                                                                                                     | Next step / owner                                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------- | ---------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-01 | Real Windows or macOS hardware behaves differently from CI runners (audio devices, permissions, drivers) | High       | High   | CI runs the real app on all three OSes; the app reports missing audio plainly instead of failing silently                               | Manual device pass ([#15](https://github.com/aasimsyed-ai/meeting-bot/issues/15))                                                                                   |
| R-02 | Speech recognition errors on real calls (accents, noise, crosstalk, jargon) reduce note quality          | High       | Medium | Every item links to evidence; edits are easy; the rules tolerate some recognition errors (BUG-014); larger multilingual model available | Measure on consented real recordings                                                                                                                                |
| R-03 | Offline notes engine misses decisions or invents tasks on unfamiliar meeting styles                      | Medium     | Medium | Validator, evidence links, held-out evaluation, "Needs review" flags                                                                    | Fresh held-out set ([#18](https://github.com/aasimsyed-ai/meeting-bot/issues/18)); Claude evaluation ([#17](https://github.com/aasimsyed-ai/meeting-bot/issues/17)) |
| R-04 | A crashed instance's helper processes block reopening the app on Windows                                 | Medium     | High   | Diagnostics in the crash recovery test                                                                                                  | Root cause and fix (see [status](status.md))                                                                                                                        |
| R-05 | Unsigned installers scare users away or are blocked                                                      | High       | High   | Signing is wired in `release.yml`; only certificates are missing                                                                        | Obtain certificates ([#16](https://github.com/aasimsyed-ai/meeting-bot/issues/16))                                                                                  |
| R-06 | Recording without consent creates legal exposure for users                                               | Medium     | High   | Clear "taking notes" state, never starts on its own, onboarding reminder                                                                | Legal review of in-app wording per market                                                                                                                           |
| R-07 | Meeting apps change window titles and detection stops working                                            | Medium     | Low    | Detection only suggests; manual start always works; rules are unit-tested                                                               | Update rules when reports come in                                                                                                                                   |
| R-08 | Electron or Chromium changes break loopback capture or the macOS path                                    | Medium     | High   | Pinned Electron version; E2E on each OS; macOS uses AudioTee instead of the broken Electron path                                        | Test before each Electron upgrade                                                                                                                                   |
| R-09 | A model download source disappears or changes                                                            | Low        | High   | SHA-256 pinned; atomic install; clear error and retry                                                                                   | Mirror models on our own release assets before public launch                                                                                                        |
| R-10 | Model licenses are misread for commercial use                                                            | Low        | High   | Licenses listed in [open-source-dependencies.md](open-source-dependencies.md)                                                           | Confirm upstream before release; show attributions                                                                                                                  |
| R-11 | Prompt injection through spoken words or screen text                                                     | Medium     | Medium | Detection, fencing, no tool access, validator, tests and an injection fixture                                                           | Extend patterns as new attacks are seen                                                                                                                             |
| R-12 | Sensitive meeting data on a lost or shared laptop                                                        | Medium     | High   | Owner-only file permissions, audio deleted after processing, retention setting, delete everything                                       | Optional database encryption                                                                                                                                        |
| R-13 | Long meetings use too much memory or CPU on older laptops                                                | Medium     | Medium | Audio written to disk as it arrives; speech in a separate process; analysis of 2 hours takes well under a second                        | Measure a real 2-hour meeting on a low-end laptop                                                                                                                   |
| R-14 | Claude API cost or outage                                                                                | Low        | Low    | Offline engine is the default and the automatic fallback; per-part caching                                                              | Show estimated cost before enabling Cloud AI                                                                                                                        |
| R-15 | Speaker labels merge or split people on real calls                                                       | Medium     | Medium | Two-pass clustering; user can rename and fix owners                                                                                     | Measure on real recordings ([#19](https://github.com/aasimsyed-ai/meeting-bot/issues/19))                                                                           |
